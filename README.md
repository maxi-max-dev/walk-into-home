# 走进这栋家

房屋空间漫游：可进入房间、连续上下楼、查看具体面板按键、AP 和屏幕位置，体验灯光和窗帘操作。

- 电脑：点击画面空白处或「锁定鼠标」进入鼠标视角，Esc 释放；W / S 前后行走，A / D 左右移动，Shift 加快。浏览器不支持锁定时可按住拖动查看。
- 手机：拖动视角，使用左下摇杆行走，右侧拖动视角。
- 「设备布局」可查看 9 个室内 AP、9 个感应器、2 个音箱、1 块中控屏、桌面旋钮与网络整理区。未定位的设备单独列出，点位均为示意。
- 「说明」中可调整行走速度、鼠标灵敏度与拖动方向；「面板清单」可查看当前方案与建议方案。当前方案只展示原表最后分页的 24 组刻字；未列点位为空白预留面板。

尺寸、陈设、面板造型与灯光为示意；灯具数量和回路配置待补充。此页面未连接真实设备。

页面可直接打开，或通过静态服务器浏览。使用 Three.js，许可已包含在页面内。
